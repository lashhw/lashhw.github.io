Projects

2024

  1. Multimodal Perception and Comprehension of Corner Cases in Autonomous Driving
    Led the team to 1st place (out of 12 teams) on multimodal understanding of autonomous driving corner cases. Enhanced LLaVA by combining LoRA fine-tuning with cross-attention layers that fuse segmentation, instance, depth, and ViT features, enabling the model to reason over complex driving scenarios. Also built a data augmentation pipeline over generated QA pairs to iteratively refine the training set.
    Course Team Project, Deep Learning for Computer Vision (Prof. Yu-Chiang Frank Wang), NTU, 2024
    Poster Code
  2. Hardware Design & Verification Flow for AQB8 Ray Tracing Accelerator
    Completed the end-to-end development for the AQB8 accelerator behind our ISCA 2025 paper, from architectural exploration to implementation and final analysis. FPGA-based prototyping on Xilinx Zynq with Vitis HLS, Vivado, and PetaLinux; standard-cell ASIC flow on TSMC 40nm with Catapult HLS and Design Compiler; functional verification with QuestaSim and power analysis with PrimePower.
    Research Project, Computer Architecture System Laboratory (Prof. Tsung Tai Yeh), NYCU, 2024
    Paper Code
  3. Implementation of a Single-Core RISC CPU: From RTL to GDSII
    Independently designed a 16-bit single-core CPU with a MIPS-like ISA and AXI4 interfaces for instruction and data memory, then carried it through the entire ASIC design flow from RTL to GDSII — logic synthesis, floorplanning, automatic place & route, and final layout generation. Verified with RTL, gate-level, and post-layout simulation, plus STA, LVS, and DRC using industry-standard CAD tools.
    Course Project, Integrated Circuit Design Laboratory (Prof. Chen-Yi Lee), NYCU, 2024
    Source code is not publicly available due to course policy.

2023

  1. Circuit Routers based on Greedy, Heuristic, and SAT Algorithms
    Implemented channel, global, and detailed circuit routers based on foundational research papers, applying optimization techniques to NP-hard routing problems. Targeted the ISPD 2008 contest benchmarks for the global router and used MaxSAT/ILP solvers for exact detailed routing; all routers were validated against the provided specifications, achieving leading results among peers in the course.
    Course Project, The Applications of Algorithms on Routing Problems (Prof. Yih-Lang Li), NYCU, 2023
    Code
  2. Memory-Efficient MultiHeadAttention Operator for TensorFlow Lite Micro
    Investigated the challenges of deploying Transformer models on microcontrollers (TinyML) through TensorFlow Lite for Microcontrollers, and identified the MultiHeadAttention layer as the critical SRAM bottleneck during on-device inference. Developed and implemented a custom TFLM operator that reduces peak SRAM requirement by over 90% (from 17MB to ~1MB) for the MobileViT-XXS model.
    Summer Internship, Embedded and Mobile Computing Lab (Prof. Pi-Cheng Hsiu), Academia Sinica, 2023
    Code
  3. Mixed-Precision Ray Tracing for Mobile Platforms
    Collaboration with MediaTek on reducing the memory bandwidth demand of ray tracing (RT) accelerators on mobile platforms. Built a functional CUDA path tracer supporting physically-based rendering and parallel traversal, then designed a novel mixed-precision RT algorithm validated via SystemC/TLM simulation, achieving 20% memory savings for key RT data structures.
    Research Project, NYCU × MediaTek Advanced Research Center (MARC), 2023
    Code

2022

  1. Real-time Parking Vacancy Forecasting System
    Led the team project awarded Best Project (out of 249 students) for an end-to-end real-time parking vacancy forecasting system. Designed the full architecture covering automated data collection, time-series model training, and real-time deployment. The LSTM model achieved low prediction error with inference fast enough for live requests, and was deployed as a serverless API on Azure Functions.
    Course Team Project, Introduction to Artificial Intelligence (Prof. Wen-Chih Peng), NYCU, 2022
